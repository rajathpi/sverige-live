Live where the source allows it

SMHI, Svenska kraftnät, Polisen and Kolada answer straight to your browser, so those pages fetch fresh data every time they open and keep refreshing while they stay open.

Updated on release days

The Riksbank and Konjunkturinstitutet cannot be called from a web page, so a GitHub Action fetches the economy figures three times every weekday and commits them only when a number has changed.

Open and reusable

The code is MIT licensed, and every chart names its source. No tracking, no keys, no build step: plain HTML, CSS and JavaScript on GitHub Pages. See the code.
